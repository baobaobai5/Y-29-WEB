# SA影视页面复刻

参考：https://safilm69.com/ 。以 2026-09-19 获取到的公开页面为内容快照，保留深色配色、桌面轮播、横向推荐、分类与影片卡片布局。数据不会自动与原站同步。

## 启动

需要 Node.js 18 或更新版本，无第三方运行依赖。

```sh
npm run dev
```

访问 http://localhost:5173 。运行 `npm run check` 检查语法、本地资源、路由和交互逻辑。

## 已实现

- 首页 19 项轮播、横向推荐滚动与 6 组影片列表。
- 7 个专题及对应真实公开资料；457 部去重影片的片库快照。
- 片名、演员、导演搜索，分类、标签、地区、语言、年份、状态筛选，排序和分页。
- 影片详情、简介展开、选集、倒序、上下集、分享、相关推荐。
- 当前浏览器的本地收藏和详情浏览记录。
- 本机视频播放，使用浏览器视频控件；所选文件不会上传。
- 登录、会员、反馈入口和明确的服务未接入状态。
- 桌面、平板与手机响应式布局；减少动态效果偏好、键盘焦点、原生对话框。

## 不属于已接通的功能

原站登录、会员支付、完整远程片库、在线播放源、跨设备同步、真实反馈提交均未接入。登录表单不发送或保存账号密码；不可把此页面作为原站登录入口。排行榜基于片库快照中的热度，不是实时全站排行。

这不是原站全功能的 1:1 后端复制。播放区域保留选集和交互，公开影视资源的实际在线播放需要合法可用的播放源与接口配置。

## 项目结构

- `dist/`：可直接托管的站点，包括 HTML、CSS、JavaScript、片库和本地图片。
- `scripts/serve.mjs`：支持深层路由回退的开发服务器。
- `scripts/validate.mjs`：不启动浏览器的渲染与行为回归检查。
- `scripts/*reference.py`、`scripts/enrich-catalog.py`：公开资料整理脚本，不复制远端脚本、登录凭据或追踪代码。

`npm run check` 已检查 457 条影片记录、7 个专题、492 张本地图片，以及搜索、空态、输入转义、主要路由、选集、收藏与浏览记录。搜索 WebMCP 工具已在支持该接口的浏览器验证。没有执行全页面像素差异比对或 Lighthouse，不宣称达到像素级 1:1。
